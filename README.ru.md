Это открытый рабочий пакет для курсовых работ по дисциплинам «Оптимизация проектирования судна» и «Контроль технического состояния судовых конструкций» Школы судостроения и морской техники Санкт-Петербургского университета при Гуандунском океанологическом университете.

Передайте AI таблицу параметров, выданную преподавателем, и укажите, кто вы. AI Agent выполнит этапы проектирования, расчёта, проверки и подготовки чертежей. Результат — один CAD-файл и одна таблица Excel.

Пакет представляет собой повторяемый инженерный рабочий процесс, а не замену имени в готовом примере. Исторические материалы являются только справочными и должны быть проверены по требованиям преподавателя текущего года.

## Начало работы

1. Откройте весь проект в AI Agent, который умеет читать и записывать локальные файлы и запускать Python.
2. Поместите актуальную таблицу параметров в `inputs/` и сообщите исходное имя студента.
3. Попросите агента сначала прочитать `AGENTS.md`, `docs/完整流程.md` и `docs/交付格式与船型制图规范.md`.
4. Промежуточные файлы храните в `work/Имя/`; в `outputs/Имя/` оставьте только один CAD-файл и один XLSX на русском языке.

AutoCAD не обязателен для разработки DXF и проверки геометрии. Устанавливайте проверенный DWG-конвертер только тогда, когда преподаватель требует настоящий DWG. См. `docs/环境与工具.md`.

Подробный процесс поддерживается в китайской версии README и связанных документах: [открыть китайскую версию README](README.md).
