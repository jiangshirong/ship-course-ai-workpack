# 放入本次教师输入

公开包有意不包含任何学生的参数行或全班名单。下载后把老师当年发的 XLSX/JSON 等参数表放在这里，并告诉 AI 姓名和新增要求。缺少时不能继续猜参数。

- 教师输入：船型、主尺度、航速等；保留原单元格、原始数值、数字格式、单位和采用精度的依据。
- 设计假设：双层底、内舷侧、板带、平台、骨架和工况等另记在 work/，不能冒充教师给定。
- 历史成品：local_reference 的 DWG/XLSX 不是任务输入，不能偷偷拿来改名。
- 老版本若把已授权的原始参数 JSON 混放在 local_reference，允许明确说明来源后仅复制参数文件到 inputs；这不授权读取同目录成品。

例如 `python scripts/read_input.py inputs/老师参数.xlsx --name 姓名` 可提取唯一匹配行。仅按单元格显示格式舍入并不自动符合教师要求；原始值与采用值都应记录。

目录下个人文件被排除出 Git 和公开 ZIP；本 README 与 .gitkeep 可公开。
