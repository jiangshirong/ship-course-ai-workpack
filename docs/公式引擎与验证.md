# 没有Excel时的重算

`scripts/course_formula.py` 是限定公式子集的独立计算器。`scripts/recalculate.py` 读取实际 XLSX 公式或本包 workbook.json，逐单元格计算，遇到不支持的内容、循环、非数值参与算术、除零或错误值即中止。不会把旧 cached 当输入，也不会把异常写成空值冒充成功。

```text
python scripts/recalculate.py work/姓名/model.json work/姓名/evaluated.json
python scripts/recalculate.py work/姓名/draft.xlsx work/姓名/evaluated.json --xlsx outputs/姓名/姓名_расчёты.xlsx
```

第二条命令仅对基本 XLSX 有效，保留公式并把本引擎算出的数值、文本、布尔值写入**新文件**的缓存。拒绝覆盖；带 Excel 扩展标记的文件拒绝缓存导出，应使用 Excel/LibreOffice。JSON 输入如需 XLSX，可先用 restore_reference_book.py 恢复基础布局，再自行完善版式并重算。恢复脚本不计算公式。

输出带 `excel_validated: false`。需如实说明“独立子集引擎重算，未在Excel内验证”，不能说“经过Excel重算”。自动重算标志只是提醒办公软件下次重新计算，不能代替已保存的结果。仅有公式、没有缓存的 XLSX，在不具备计算能力的预览器中会显示空结果。

最终验收命令：`python scripts/validate_xlsx.py outputs/姓名/姓名_расчёты.xlsx --report work/姓名/xlsx_check.json`。它逐公式检查可读缓存和与当前重算结果的一致性，包括数值、文本和布尔，错误返回非零状态。缓存通过仍不代表工程正确；T型还须运行check_t_assignment.py，其范围包含主表12组和CL-F4组。合成已知答案运行verify_examples.py，详见组合截面与已知算例.md。

支持普通 A1/绝对引用、带引号或不带引号的工作表引用、矩形区域（聚合函数中）、数字/文本/布尔、算术/比较/连接、IF、AND、OR、NOT、SUM、MAX、MIN、COUNT、SQRT、ABS、SIN、COS、PI、ROUND、INT、CEILING、CEILING.MATH、FLOOR、TRUE、FALSE。不支持名称、数组/动态数组、日期运算、宏、外部工作簿、3D引用、隐式交叉和完整Excel类型转换。混合文本/数字比较拒绝执行。AND/OR仅支持标量参数。中文/俄文标签被算术误引用时直接报错。

本次修正了早期试用引擎的文本比较、无引号跨表引用、IF未选分支被错误执行、ROUND的中点规则、负号/幂优先级、引用区域中文本被当0计数等问题。例如：

| 表达式 | 早期引擎 | 修订引擎 |
|---|---:|---:|
| `"foo"="bar"` | TRUE | FALSE |
| `IF(1,2,1/0)` | 除零 | 2 |
| `ROUND(2.5,0)` | 2 | 3 |
| `-2^2` | -4 | 4 |
| `2^3^2` | 512 | 64 |

计算顺序与取整语义依据[Microsoft运算顺序](https://support.microsoft.com/en-gb/excel/the-order-in-which-excel-performs-operations-in-formulas)和[ROUND说明](https://support.microsoft.com/en-us/excel/functions/round-function)。这里实现的是文档化子集，未宣称与所有 Excel 行为完全兼容。

运行 `python scripts/test_workpack.py`：覆盖反例、错误中止、输入改变后的重算、数字/文字/布尔缓存往返、板带闭合、错误跨度/高度、型材性质关联、独立矩形积分及历史公式回归。历史三本底稿中有缓存的公式共 6475 个（2876+2915+684）；历史结果复现只是回归，**不是独立公式正确性证明**。对新船还须改变输入后核对关键中间量、真实几何、所有构件要求和缺失工况。
