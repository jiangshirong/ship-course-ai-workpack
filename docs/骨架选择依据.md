# 骨架选择：查证结果与课程使用边界

查证日期：2026-09-24。本文是开源整理过程中的研究记录，不代表工作包已完成，也不代表下列资料就是本次任课教师采用的教材。

## 结论

船型 C（本项目的干货船）不能唯一决定所有部位的骨架。应分别确定上甲板、船底、内底、舷侧、下层甲板的骨架，并检查相互连接。纵骨架与横骨架均包含纵向和横向构件，名称主要描述普通加强构件的主方向。

权威资料可以提供选择原则和适用条件；不能把不同船种、不同规则中的船长阈值合并成一个适用于所有 C 型船的规则。

## 与本项目案例的关系

- C型109 m案例：教师针对本船要求修正甲板、船底骨架；最终修订采用上甲板、船底和内底纵骨架，下层甲板按C型示例布置。它可作为本案例明确依据。
- 另一个对话中教师曾明确指定“全横骨架”。这与上面的 109 m 修订要求不是同一分支。工作包因此保留 `C_transverse`；如果本次任务的教师明确指定全横骨架，就选择该分支并保留证据，不能把两套结构拼在一起。
- 该个例与较长船舶重视纵向加强的教材原则相符，但不能反推出所有C型船都采用相同结构，也不能反推出精确的通用100 m界限。
- T型课程要求中，中部甲板、船底采用纵骨架；其他部位仍应单独记录，不写成“全船所有部位纵骨架”。

## 工作包应如何使用这些依据

1. 读取船型、船长、布置和教师附加要求，明确船长定义与单位。
2. 按部位列出拟用骨架、采用理由、资料来源及性质（教师指定、教材建议或适用规范要求）。
3. 教材建议可作为初选依据；仍需核验结构布置和计算，不能因为船长落入某范围就宣称所有校核通过。
4. 如果已找到的依据能确定初选，AI应给出有来源的方案，不把本可研究的问题推回学生。
5. 只有课程明确要求与资料冲突、关键输入缺失或现有模板不适用时，才指出具体待确认项。尚未核实的课程分界不得伪装为教师规定。
