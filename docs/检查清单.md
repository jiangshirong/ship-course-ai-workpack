# 后续生成作业的检查清单

本清单供每次生成作业使用，不能因辅助工具回归通过而全部勾选。2026-09-25工具验证范围见版本记录.md。

先读[交付格式与船型制图规范](交付格式与船型制图规范.md)。格式项与工程计算项分开核对：格式合格不代表结构计算合格，计算通过也不代表图面已经按教师示例表达。

- [ ] 学生行唯一，主尺度、单位和采用精度与老师表一致。
- [ ] 若教师指定使用参数表显示值，图纸、XLSX和中间模型均使用同一显示精度，没有混用隐藏全精度值。
- [ ] 各部位骨架来源明确，没有编造精确阈值。
- [ ] T/C分支明确且只有一个分支进入最终图纸和XLSX；若出现“全横骨架”和“按示例加强甲板/船底”等不同要求，已记录本次教师要求的优先级。
- [ ] 自选几何和工况单列，没有隐含沿用旧数据。
- [ ] 间距闭合、左右对称、真实数量与计算数量一致。
- [ ] 平底/舭弧/直舷侧各自闭合，内舷侧高度与梁拱坐标统一；不能仅核总周长。
- [ ] 支承跨度和末端间距来自实际DWG实体，不能只核对源码中的常量或fallback值。
- [ ] 同工况内外差压，板厚包含适用最小值与腐蚀增量。
- [ ] HP与带板组合截面独立复算，带板面积和单位正确。
- [ ] 型材枚举使用与工作簿一致的中和轴/惯性矩；声称最轻时留存全部适用候选。
- [ ] T型16组含CL-F1～4，逐项核对W和明确的腹板要求；附加构件页没有被主表汇总漏掉。
- [ ] T型中部甲板/船底纵骨架、内舷侧交接线、中纵舱壁0.5份和双层舷侧内的必要/不必要加强筋均与教师示例逐项对照。
- [ ] C型按所选分支检查双层底、舱口围板、支柱/支承、舷侧肋骨；C纵骨架分支的下层甲板横梁和加强纵桁没有被油船模板替换。
- [ ] 长船 C 型的双层底桁架/桁材按教师示例加强；人孔和检修开口满足人员通过及使用高度，不直接沿用过小或过高的历史样本。
- [ ] 等效梁中的型材名称、A、I、重心均关联本次选型，未残留旧HP行号。
- [ ] D-L/D-W各自列实际工况与控制位置；相同设计压力也有分别推导的依据。
- [ ] 等效梁无漏项/重复，半剖面与全剖面计数一致。
- [ ] 中和轴、I、甲板W、船底W与要求值直接汇总，不足项已处理。
- [ ] XLSX确实重算，无公式错误，没有用历史cached冒充新值。
- [ ] 实际最终XLSX含本次数值缓存；文字/布尔结果也核对，说明所用引擎及是否经过Excel验证。
- [ ] validate_xlsx.py通过；T型check_t_assignment.py通过其已实现范围。缓存成功与工程正确分开判定。
- [ ] 独立截面积分按板条方向计算自身I、按实际弧段计算重心；不能复制工作簿几何后声称完全独立。
- [ ] “通过几项”明确列出项目，重复汇总不算独立校核；板带、骨材、强支承与总纵分开报告。
- [ ] 表格无截断/乱码/单位错误和其他船型内容。
- [ ] 最终XLSX只有俄语，姓名使用原文俄文，不含RU/CN、英文转写、AI/来源/日期/免责声明等过程性长段落；只保留本船适用计算。
- [ ] CAD包含纵向布置、 中横剖面、上甲板、船底/内底、舷侧展开五类基本视图及本次要求详图；俄文显示正常，没有白色背景板或制作说明。
- [ ] DXF结构审计与几何核对完成。
- [ ] 无AutoCAD时已用其他DXF查看器检查全图、中横剖面、平面、人孔、局部；若交付DWG，再用DWG引擎重新打开保存后的文件复核。
- [ ] CAD与XLSX板厚/型材/数量/高度/间距一致。
- [ ] CAD材料表按当前行数安排空间，没有覆盖剖面、尺寸链、舱名或引线。
- [ ] 分区荷载保留同工况配对证据，未把满载外压用于压载、未把独立MAX包络互减。
- [ ] 姓名、文件名正确，无旧姓名。
- [ ] 若交付DWG，关闭DWG引擎后输出目录只含`原文姓名_проект.dwg`和`原文姓名_расчёты.xlsx`，无DXF、DWL/DWL2、PNG、JSON、日志、备份或中文表格；已运行`check_delivery.py`。只有DXF时明确标注原生DWG未完成。
- [ ] 最终DWG＋俄语XLSX，未执行检查明确报告。
