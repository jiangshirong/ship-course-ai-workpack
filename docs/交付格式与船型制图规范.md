# 交付格式与船型制图规范

本文把两个作业对话中已经确认的最终格式要求整理成可复用规则。它们是课程工作流约束，不是对未来教师要求的替代；新年度教师明确修改时，以新要求为准，并把变化写入本次 `work/` 记录。

## 所有船型都适用的交付格式

最终 `outputs/原文姓名/` 只能有两个文件：

```text
原文姓名_проект.dwg
原文姓名_расчёты.xlsx
```

姓名使用老师参数表里的原文俄文姓名，不使用英文转写，不加 `RU`、`CN` 或其他版本标记。计算表只交俄语版；中文译本、DXF、PNG、JSON、日志、备份和说明文件都放在 `work/`。`.dwl`、`.dwl2` 是 AutoCAD 打开图纸时的锁定文件，关闭图纸后不能留在交付目录。

最终 CAD 和 XLSX 中不要出现“AI制作”“来源说明”“审查记录”“版本说明”“免责声明”、日期串或过程性长段落。图纸只保留课程图名、尺寸、构件名称、规格和必要的自然俄语标注；计算表只保留本船适用的输入、计算、选型、等效梁和结果。设计假设和证据在 `work/` 保存，只有教师模板本来要求的假设栏才进入最终表格。

CAD 使用毫米作为绘图单位，采用真实 CAD 图元、图层、线型和尺寸标注。不要画一个白色背景板来模拟预览页面；打开 DWG 后应能在老师使用的 CAD 中看到黑色模型空间中的结构。俄语必须使用能够在 AutoCAD 中显示的 Unicode 文字样式，不能用英文转写代替俄文。

主尺度的采用精度以本次教师明确要求为准。如果教师明确要求按参数表显示值（例如显示为整数或一位小数）完成，就记录显示值并使用该精度；不能一边把图上写成显示值、一边在计算中偷偷使用单元格里的隐藏全精度值。

课程图纸至少逐项检查以下五类视图：`продольная`（纵向布置）、`поперечная`（中横剖面）、上甲板平面、船底/内底平面、舷侧展开。教师当年示例若另有下层甲板、舱口或局部详图，则一并保留；不能因为自动生成方便而只交一张图。所有视图的板厚、骨材、肋距、标高和构件编号必须来自同一份本次设计数据。

## T 型油船

T 型不能只把船名换成油船。按照两个作业中教师对油船的批注，交付前至少确认：

- 中部上甲板和船底采用纵骨架；其他部位按本船教师要求和资料单独记录，不能写成“全船所有部位都是纵骨架”。
- 双层底、双舷侧、平台、内舷侧交接线和中纵舱壁在剖面及相应平面图中连续可见。骨材根部必须接到板，不得悬空；双舷侧内的短线、斜线或加强筋只有在教师示例和本船结构确实需要时才画。
- 等效梁必须包含与实际中横剖面相符的内舷侧和中纵舱壁。采用半剖面计算时，中纵舱壁按 `0.5` 份计入，并在同一计数口径下换算全剖面；不能只在图上画出而在表中漏掉。
- 适用的纵骨间距用 50 mm 的倍数，左右对称并闭合到实际宽度，图面间距和计算间距相同。内底板的采用厚度不得低于船底外板的适用计算要求。老师示例中没有的多余斜线应删除，但不得误删真实支承。
- 甲板、船底平面图要画出内舷侧的相接线；甲板纵骨和内舷侧、强框架的连接位置要与剖面一致。

总纵强度始终要做。结果页直接给出中和轴相对基线的位置、剖面惯性矩、甲板和船底的截面模数，以及与要求值的比较；只列主表 12 组而漏掉 CL-F1～4 不算完成。

## C 型干货船

C 型保留两个分支，是因为两个作业中出现过“全横骨架”和“按 109 m 教师示例加强甲板、船底”的不同明确要求。分支选择按本次教师指令，不按船长自行猜阈值：

| 分支 | 采用条件 | 图纸与计算表达 |
|---|---|---|
| `C_longitudinal` | 教师要求按 109 m 示例加强，或明确指定甲板/船底纵骨架 | 上甲板、船底和内底按该示例采用纵骨架；舷侧按示例采用横骨架；下层甲板保留横梁，并在舱口边设置示例中的加强纵桁/支承。 |
| `C_transverse` | 教师对本次任务明确说“全横骨架” | 上甲板、下层甲板、船底、内底和舷侧按教师指定的横骨架方案表达；不把 `C_longitudinal` 的纵骨、加强纵桁或型材表混进来。 |

两条分支都要画出干货船实际存在的双层底、舱口、舱口围板、支柱/支承和相应肋骨。舱口附近的下层甲板不能因为套用油船模板而自动改成纵骨架；按 C 型示例保留横梁并加强纵桁时，图纸、跨度、型材和等效梁必须同步。老师若重新指定分支，保留旧方案在 `work/`，最终 CAD/XLSX 只保留一个分支。

长船的 C 型示例中，双层底桁架/桁材系统需要按示例加强；加强的位置、跨度和截面要在图纸与计算表中一致。人孔和检修开口要满足人员通过和使用高度的要求，不能沿用过小或过高的历史样本尺寸。

C 型也必须做适用的总纵强度，且只保留本船相关的计算页。不能把油船的双舷侧、中纵舱壁或 CL-F 附加构件无条件复制到干货船；同样不能因为选择横骨架就省略总纵强度检查。

## 最终验收

交付前运行：

```text
python scripts/check_delivery.py outputs/原文姓名 原文姓名
python scripts/validate_xlsx.py outputs/原文姓名/原文姓名_расчёты.xlsx
```

如果交付 DWG，关闭 AutoCAD 或其他 DWG 引擎后，再检查输出目录是否仍只有上述两个文件。实际打开保存后的 DWG，逐视图与教师示例对照；不能用 DXF 审计、实体数量或“文件能打开”代替原生 DWG 验收。没有 DWG 引擎时，可以交付 DXF 中间结果给用户继续转换，但必须明确标注 DWG 尚未完成。
