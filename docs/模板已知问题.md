# 历史模板的已知边界与迁移必查项

历史JSON保留原貌供追溯；不能把这里列的问题当成“所有模板已经正确”的反向保证。

| 问题 | 已补工具 | 仍须做的工作 |
|---|---|---|
| D19/D21以固定2000mm减邻接板带，换尺度可能为负 | prepare_t_model分四段闭合 | 检查分段宽度、曲线重心、板带压力控制点及实际CAD |
| 旧HP行号与新型号脱节 | 主表及CL-F按身份绑定 | 换型后复核面积、I、重心、数量、单位与下游结果 |
| Балки!E22/E23共用Нагрузки!B85混合包络 | 两区独立工况入口 | 每个压力都要有同点、同吃水、同相位的依据；“分成两格”本身不证明正确 |
| Листы仍使用旧荷载控制点/混合包络，骨材已分区 | 验收说明显式列出 | 按板带逐一说明覆盖哪些工况；共同保守包络可以使用，但要证明覆盖且口径一致，不能一概声称偏保守 |

`Листы`各板带并不是全部引用B85：该格对应甲板混合包络，其他行有各自引用。审查时必须按实际单元格追溯，不要把“存在混合口径”写成“所有板都用同一格”。

内舷侧梁拱`D+f·b/(B/2)`在b从外舷起算时正确，不属于待修模板错误。不得改为中线坐标公式而仍把b当距外舷距离。

## 两个压力最大值不能随意相减

例：工况A内压50、外压0；工况B内压20、外压15。逐工况净压包络是MAX(50,5)=50，而MAX(内压)−MAX(外压)=35，会漏掉控制工况。压载工况也不能借用满载外压来抵消。

只有能证明两侧值同时作用于同点、同方向组合时，才能按该组合求差，再在所有相关组合中取控制值。暂缺抵消依据时可另算不计有利外压的对照工况；它是敏感性/保守方案，不能冒充已经取得教师或规范裁定。

## 图纸总表扩大后的布局

主骨材12组加CL-F4组需要逐项列示，或采用无歧义的分组清单。行数增加后同时重新分配表格和剖面的占用区域：表格高度至少为(数据行数+表头行数)×行高，加上下留白。不能只把7行改成16行、仍沿用旧表框和剖面位置。

最终必须查看实际DWG的总表、甲板尺寸链、剖面、舱名和引出标注；实体数量、DXF审计与文字存在均不能证明没有遮挡。绘图脚本的fallback值也不能替代实际实体量测。
