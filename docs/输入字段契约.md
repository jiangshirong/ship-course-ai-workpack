# T型配置字段契约（schema_version 3）

教师原始参数存inputs；本次已选择的设计配置存work/姓名/t_model.json。完整可读格式见examples/t_model.example.json，但其中荷载、材料假设与型材是合成演示值，不是新作业默认值。文件命名、视图数量、语言和输出目录属于[交付格式与船型制图规范](交付格式与船型制图规范.md)，不应靠旧模板隐含。

根对象必须有schema_version=3、given、layout、design_inputs、deck_cases、profiles。旧v2配置缺少明确工况配对及附加构件字段，应先迁移；脚本不会静默继承旧模板常量。

| 字段 | 单位/格式 | 意义 |
|---|---|---|
| given.L/B/D/draft | m | 教师主尺度与采用吃水；原始值、显示精度另保留 |
| given.Cb | 无量纲 | 方形系数 |
| given.speed_kn | kn | 航速 |
| layout.B/D/R/side_width/double_bottom/camber | m | B、D必须与given一致；R为舭半径，b为距外舷的双舷侧宽，hdd为内底高，f为中线梁拱 |
| layout.flat_bands_m | 7个正数，m | 总和=B/2−R（含半龙骨板） |
| layout.arc_bands_m | 2个正数，m | 总和=πR/2 |
| layout.side_bands_m | 9个正数，m | 总和=D−R（含舷顶列板） |
| layout.inner_bands_m | 7个正数，m | 总和=D+f·b/(B/2)−hdd |
| layout.workbook_inner_side_top_m | m | 计算模型内舷侧顶部，须等于D+f·b/(B/2) |
| layout.cad_inner_side_top_m | m | 准备制图时的目标值；最终必须由实际CAD反读核对，填相同数字不算独立量测 |
| layout.frame_spacing_m | m | 肋距 |
| layout.frames_per_support | 正整数 | 强支承间隔的肋距数；两者乘积为纵骨跨度 |
| layout.platforms_m | 3个递增数，m | 位于内底以上、舷侧甲板以下 |
| layout.wing_x_from_shell_m | 2个递增数，m | 双舷侧甲板纵骨距外舷坐标，均在0到b之间 |
| profiles | 16个身份→HP名称 | 主表12组，加CL-F1、CL-F2、CL-F3、CL-F4；名称须存在于公开目录 |

layout.longitudinals必须有deck、bottom、inner_bottom三个对象，每个对象包含以下**5个**字段：

| 字段 | 单位/约束 |
|---|---|
| x_from_center_m | 从中线向外的正坐标数组，递增、不重复、不越过内舷侧；当前甲板最多14个 |
| calculation_spacing_m | m；不小于相邻坐标和两端支承之间的最大间隙 |
| full_count | 整数，全剖面数量=坐标数×2 |
| support_span_m | m，几何支承跨度=frame_spacing_m×frames_per_support |
| calculation_span_m | m，须与实际支承跨度一致 |

## 显式设计假设

design_inputs中每项形如`{"value":18,"basis":"本次选定的舱长，说明布置依据"}`。全部必填：

| 字段 | 单位 | 写入位置 |
|---|---|---|
| tank_length_m | m | Исходные данные!B26 |
| density_t_m3 | t/m³ | B28 |
| airpipe_height_m | m | B29 |
| valve_pressure_kpa | kPa | B30 |
| service_years / corrosion_start_year | 年 | B31/B32 |
| yield_mpa | MPa | B33 |
| eta | 无量纲 | B34；σn仍遵循本模板235/η定义，适用性需核实 |
| ax / avax | 本课程公式系数 | B36/B37 |
| gravity_m_s2 | m/s² | B38 |
| midship_coefficient | 无量纲，0<Cm≤1 | B39 |
| floor_k1 / floor_k2 | 本课程公式系数 | B51/B52 |
| cl_web_min_mm | mm | Параметры модели!B9；须说明立柱腹板最小厚度依据 |

明确记录假设不等于自动证明其适用性。不能把附加构件页B11的“舱壁板最小厚度”误用为立柱腹板最小厚度。不得静默沿用旧船15.5m舱长等参数。

## 压力工况

deck_cases.cargo/wing各为非空数组（每区至多30项）。每项至少包含condition、inside_kpa、outside_kpa、basis、inside_kind和combination_mode。

- `inside_kind`为`case_value`（单一工况的值）或`envelope`（多个工况包络）。
- `combination_mode=no_counterpressure`：outside_kpa必须为0。表示本项不计有利外部抵消，仍需审查外压向内等其他控制工况；不是宣称船舶永远没有外压。
- `combination_mode=coincident`：inside_kind必须为case_value，且提供inside_state、outside_state。两者都含case_id、point_id、phase_id、draft_m、z_m，必须匹配；另填combination_basis说明同工况组合的资料或推导依据。

不得把MAX得到的内压包络与另一个外压包络直接相减。标注“压载5m”的内压不能和“满载9.4m”的外压配对。缺少同时性依据时，不得靠有利抵消把型材减小。

数字压力仍是本次载荷推导的结果；改变主尺度、液位、吃水、舱长、系数、密度或控制点后必须重算并重填。元数据只能检查声明是否一致，不能代替真实荷载推导。工作簿F列会保留配对信息以便验收。
