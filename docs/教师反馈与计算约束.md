# 教师反馈与约束

来源：2026课程记录及两个主要对话的后续修订，以下是匿名归纳，不是新增规范条款认证。

交付格式的统一约定见[交付格式与船型制图规范](交付格式与船型制图规范.md)：最终只交原文俄文姓名的 DWG 和一份俄语 XLSX；不要在成品中加入 AI、来源、日期或过程说明；DXF、DWL/DWL2 和中文表格只留在工作目录。

| 问题 | 执行要求 |
|---|---|
| 纵骨间距任意小数 | 适用位置采用50 mm倍数，保持对称，闭合尺寸，计算与几何一致 |
| 内底约束缺失 | 把不低于船底所需厚度的课程要求写入适用公式，不只手改显示值 |
| 人孔过小过高 | 重查通行净空、平台下缘高度及干涉；历史Ø1000、下缘300 mm是案例值 |
| 多余斜线 | 按对应图例去掉非必要线，不误删真实支承 |
| 油船骨架错误 | 遵守本课程中部甲板、船底纵骨架要求 |
| 等效梁漏项 | 补实际内舷侧、中纵舱壁，半剖面中线0.5份约定全表一致 |
| 骨材悬空/冲突 | 根部接触板，避让强构件，同步平面和剖面 |
| 交接线缺失 | 在相关平面图表达内舷侧位置 |
| 结果未汇总 | 等效梁页列中和轴、I、甲板W、船底W及要求值比较 |
| 横骨架省略总纵强度 | 不论骨架系统均完成适用总纵校核 |
| 压载压力口径错误 | 同工况内外差压，明确压载吃水和满空组合 |
| C型修订要求 | 补舷侧展开下方双层底，按本船分支处理甲板/船底及加强纵桁 |
| 混入其他船型 | 最终表只含本船计算 |
| 成品格式混乱 | CAD按教师示例完成纵向布置、中横剖面、甲板、船底/内底、舷侧展开等基本视图；不得只交一个视图或画白色背景板 |
| C型分支混用 | 明确选择C纵骨架或C横骨架；C纵骨架下层甲板按示例保留横梁并加强纵桁，全横骨架要求则不得混入纵骨架分支构件 |
| C型长船细节 | 双层底桁架/桁材按教师示例加强；人孔和检修开口要能供人通过且高度适宜，不能照抄过小或过高的历史样本 |

历史流程未证明已完成全部屈曲、极限强度、疲劳、人孔局部强度等检查。型材通过、DXF审计无错、DWG能打开均不等于完整工程认可。2026-09-24整理时未重跑/测试，后续辅助工具验证范围另见版本记录.md。
